# 베르영어 AI Office

영어강사·학생용 영어지문 수업자료(분석지 · 단어장 · 워크북 · 변형문제 · 서술형 대비)를
기획하고 만들고 검수해서 판매하는 일을, AI 직원 33명이 픽셀 사무실에서 하루 단위로 돌리는 화면입니다.

## 직원들이 실제로 하는 일

Claude에서 이 페이지를 열면 **실제 작업 모드**로 돌아가요. 라이브 오피스의 **작업 지시서**에 영어 지문을 붙여넣고
"오늘 업무 시작하기"를 누르면, 직원들이 자리에 앉아 있는 동안 실제로 아래 결과물을 써요.

| 팀 | 실제로 만드는 것 |
|---|---|
| 수요조사팀 | 붙여넣은 카페 요청글·시험 범위 메모 정리 (메모가 없으면 건너뜀, 인터넷 검색은 못 함) |
| 자료기획팀 | 지문 진단 + 제작 계획 → 대표 결재 카드에 올라감 |
| 분석지·단어장팀 | 문장별 끊어읽기·해석·구문 분석지, 문맥 뜻 단어장 + 확인 테스트 |
| 워크북·변형문제팀 | 어휘 빈칸·어법 선택·어순 배열·해석 쓰기 워크북, 수능형 변형문제 5문항 + 해설 |
| 서술형대비팀 | 조건 영작·요약문·어법 고쳐쓰기·요지 쓰기 + 모범답안·채점기준 |
| 검수팀 | 모든 문항을 직접 풀어 정답 검증한 검수 보고서 |
| 홈페이지 디자인팀 | 상세페이지 문구 (썸네일 문구 3안 포함) |
| 마케팅팀 | 황영카·기출비 카페 홍보글 + 블로그 포스팅 |
| 자료관리팀 | 상품 코드·파일 이름·스프레드시트에 붙여넣을 한 줄 |
| 비서실 | 오늘 결과 브리핑 + 대표님 할 일 |

- 결과물은 **오늘 결과물** 창에서 보기·복사·`.docx` 저장, 실패하면 "다시 만들기".
- 대시보드의 **결과물 창고**에 세트별로 저장되고, "판매용 세트 한 파일로 저장"으로 5종을 한 워드 파일로 받을 수 있어요.
- 지문 하나에 AI 작업이 약 10번 돌고, **대표님의 Claude 사용량**을 씁니다.
- AI가 쓴 자료는 판매 전에 반드시 검수 보고서와 함께 직접 확인하세요.
- 사이트 업로드·카페 게시·결제는 하지 않아요. 고객지원팀·회계팀은 연결된 데이터가 없어서 "연동 대기"로 쉬어요.

로컬(`npm run dev`)이나 다른 곳에 올린 사본에서는 AI를 부를 수 없어서 **연습 모드**(연출만)로 돌아요.

## 실행

Node.js 20.19 이상이 필요합니다.

```bash
npm install
npm run dev      # http://localhost:3000
```

화면 위쪽 **"오늘 업무 시작하기"** 를 누르면 직원들이 출근합니다.
직원을 클릭하면 프로필이 열리고, 오른쪽 **대표 지시창**에 "마케팅팀 뭐해?", "왜 늦어져?", "민트 뭐해?"처럼 물어볼 수 있어요.
하루가 끝나면 **📤 보고 복사**로 일일 브리핑을 텍스트로 복사해 카톡·노션 어디든 붙여넣을 수 있습니다.

```bash
npm run build    # 타입 검사 + dist/ 에 정적 사이트 생성
npm run preview  # 빌드 결과 미리보기
```

## 팀 구성 (12팀 · 33명 · 이름은 전부 색깔)

| 팀 | 팀장 · 팀원 | 하는 일 |
|---|---|---|
| 🔎 수요조사팀 | 스카이 · 레몬 · 세이지 | 학평·모의고사 일정, 학교별 내신 범위, 카페 자료 요청글 조사 |
| 💬 고객지원팀 | 피치 · 라일락 | 주문·다운로드 문의 정리, 답장 초안 (**연동 대기**) |
| 💡 자료기획팀 | 코랄 · 머스타드 · 민트 | 이번 주 제작 후보 10개 → TOP 3 |
| 📖 분석지·단어장팀 | 올리브 · 베이지 · 그레이 | 구문·해석 분석지, 문맥 기준 단어장 |
| 📝 워크북·변형문제팀 | 버건디 · 오렌지 · 틸 | 빈칸 워크북, 순서·삽입·빈칸·어법 변형문제 |
| ✍️ 서술형대비팀 | 인디고 · 라벤더 · 바닐라 | 조건 영작·요약문, 모범답안·채점기준 |
| 🛡️ 검수팀 | 네이비 · 아이보리 · 로즈 | 정답·해설 대조, 오탈자·서식 |
| 🎨 홈페이지 디자인팀 | 핑크 · 크림 · 시안 | 상세페이지, 썸네일, 워터마크 견본 PDF |
| 📣 마케팅팀 | 마젠타 · 체리 · 그린 | 황영카·기출비 카페글 + 블로그 포스팅 초안 (게시는 대표 직접) |
| 🗂️ 자료관리팀 | 에메랄드 · 카키 · 차콜 | 스프레드시트·관리자페이지 등록 정보, 최종 파일 버전 관리 |
| 🧾 회계팀 | 골드 · 실버 | 매출·입금·정산 (**연동 대기**) |
| 📋 비서실 | 화이트 · 블루 | 전사 한줄보고, 대표 최종 브리핑 |

하루 흐름: 출근 → 수요조사 → 고객 문의 확인 → 제작 후보 10개 → TOP 3 → **대표 승인** → 분석지·단어장
→ 워크북·변형·서술형 → 검수 → 상세페이지·홍보글 → 등록 준비·정산 → 비서실 브리핑

## 내 마음대로 바꾸기

**`company.config.ts` 한 파일만 고치면 됩니다.** 팀 이름·하는 일, 직원 이름·옷색·혼잣말,
오늘의 결재 안건(`TODAY_PICK`), 결과물 창고 목록, 공개 링크, 연동 대기 팀이 전부 여기 있어요.

- 부서 `id`(`research`, `brand` …)는 바꾸지 마세요. 엔진이 하루 순서를 이 id로 돌립니다.
- 부서는 12개, 한 부서 최대 3명(책상 3개), 팀장(`lead`)은 1명.
- 고객지원팀·회계팀도 일하게 하려면 `PENDING_INTEGRATIONS` 를 `{}` 로 비우세요.

## 🔒 관리자페이지·스프레드시트 링크

이 저장소는 **공개**라서 관리자페이지 주소(`key=` 포함 — 비밀번호와 같음)와 스프레드시트 주소는 코드에 넣지 않았습니다.
내 컴퓨터에서만 대시보드에 띄우려면:

```bash
cp .env.example .env.local   # 그리고 .env.local 에 두 주소를 붙여넣기
npm run dev
```

`.env.local` 은 git 에 올라가지 않고, `npm run build` 결과물에도 들어가지 않아요 (개발 서버에서만 보임).

```

src/App.tsx               화면 (라이브 오피스 / 대시보드 / 대표 지시창 / 모달)
src/game/sim.ts           하루 시나리오·직원 상태머신·지시 처리
src/game/world.ts         사무실 맵·가구·충돌 그리드
src/game/OfficeWorld.tsx  픽셀 오피스 렌더러
src/game/report.ts        일일 브리핑 생성 (텍스트 복사용)
src/ai/prompts.ts         팀별 업무 지시서 (자료 양식을 바꾸려면 여기)
src/ai/job.ts             지문 1개 → 12개 결과물을 실제로 만드는 작업 단위
src/ai/docx.ts            워드(.docx) 저장
src/ai/store.ts           결과물 창고 (Claude 페이지 저장소)
src/Work.tsx              작업 지시서 · 오늘 결과물 · 문서 보기 창
src/links.ts              대시보드 링크 패널 (공개 링크 + .env.local 비공개 링크)
```
